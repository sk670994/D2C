# AdSpy framework implementation v6

React Bits: AnimatedList-style research pulse and loading intelligence.
Vengeance UI: rolling per-digit KPI animation.
Skiper UI: creative image reveal / sweep interaction.
Animmaster: progressive Show More / Show Less disclosure.

The implementation is source-pattern based and locally integrated; the app does not install four unrelated bulk packages. React Bits and Skiper expose copy-ready components, while Vengeance and Animmaster patterns are integrated into the existing React/Framer Motion stack.

A persistent Research Pulse is shown after a search so the GK facts, market notes, Zooptrack notes, research tips and Santa-Banta item are actually visible instead of existing only inside a loading screen.
