# Zooptrack 3D Marketing Foundation

Implements the requested visual direction:
- Signal Field home
- Radar language for AdSpy
- Conveyor Decision Loop
- Ledger Stack pricing
- Unfold FAQ primitives
- Cockpit / Archive SVG primitives for the later authenticated/legal wrappers
- shared motion, SVG and CSS 3D language
- prefers-reduced-motion handling
- Framer Motion scroll parallax, already available in the repo

The package deliberately does not overwrite the authenticated AdSpy or Dashboard implementations.
